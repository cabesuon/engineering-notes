Week 1 — Foundations

Mission:
Lay the foundations of Engineering Notes.

Objectives

• Create the Engineering Notes repository.
• Define what the project is about.
• Decide on a simple technical approach.
• Create the first version of the website.
• Define a roadmap for the learning journey.

Results

The Engineering Notes repository was created as a public GitHub repository.
The initial website was built using plain HTML, CSS and JavaScript. I deliberately decided not to use a framework. At this stage, I want the content and the learning process to be more important than the technology used to present them.
The initial README was also created, including the purpose of the project, the roadmap and some guiding principles.
The first version of the homepage is now in place, and the project has a basic visual identity. I chose Inter as the main font and kept the design deliberately simple.
The roadmap was defined around several areas:
• Refreshing mathematics for AI.
• Strengthening Python for machine learning.
• Reading and discussing classic AI papers.
• Building small AI projects connected to GIS.
• Exploring software architecture in the age of AI.

Reflection

What did I learn?

The first thing I learned is that starting a personal project is easier when the purpose is clear.
I originally thought about creating a personal website because I never really knew what I would put on one. Once I connected it to my AI learning journey, it became much easier to decide what the website should contain.
I also realised that I don't need to start with a sophisticated technical solution. Plain HTML, CSS and JavaScript are enough for what I need right now.

What surprised me?

I spent more time thinking about what this project should mean than actually writing code.
That was not necessarily a bad thing. It made me realise that this is less about building a website and more about creating a place where I can document how I learn and how my thinking changes over time.

What do I want to explore next?

The next step is to start adding real content.
I want the journal to record the process week by week, while separate notes will contain things I learn and want to be able to return to later.
For the next iteration, I want to start reconnecting with the mathematics behind AI and continue building the basic structure of the website.
